# Axiom-Midi
a Professional customizable MIDI Keyboard made by PieSquared. Has 1 octave worth of touch buttons (12 Key), 12 LEDs below them, 2 Push button rotary encoders, 6 Buttons, and a 0.96in LCD. Requires software to run and customize

## Why did I make this project

I mainly wanted to challenge myself and see what I could do without using a devkit, and what better way to do this by making something about what I love, Music!

Onshape Document: https://cad.onshape.com/documents/4fcb2e2092c7b8f6c2e7c126/w/a1f5aab5071a20b775f20b63/e/1a1cbc1f4bd564a001b92cae

## Features
- Customizable keys (Mainly used for soundboard)
- 12 touch keys
- 2 Pushbutton Rotary Encoders (Can be used for Octave changes, ect.)
- LCD
- Customizable LEDs
- Custom firmware
- Small formfactor
